友達紹介カード　教室共通テンプレート　作成手順


A4・10面の名刺用紙に、91×55mm の友達紹介カードを表10枚・裏10枚で印刷するための一式です。
教室ごとに変えるのは、教室名・写真・QRコード2つ の4点です。


■ このフォルダの中身

  友達紹介カード_編集用テンプレート.html … 編集画面。ブラウザで開いて使います
  Word配置.bat                          … Windows用の起動ファイル
  Word配置.command                      … macOS用の起動ファイル
  Word配置.py                           … 全OS共通の処理（Linuxはこれを実行）
  Word配置ツール（フォルダ）             … 上の処理が使う部品。触らないでください
  readme.txt                            … この手順書

まずフォルダごとコピーして、教室ごとの作業フォルダを作ってください。
元のフォルダは共通テンプレートとして残しておきます。


■ 初回セットアップ（作成するPCごとに1回）

  Node.js 22以上とPython 3.10以上をインストールしてください。
  WindowsではPythonをPATHに追加する設定を有効にします。
  初回の依存関係・Chromiumのダウンロードにはインターネット接続が必要です。
  Codexのインストールは不要です。

  このフォルダをターミナル（Windowsではコマンドプロンプト）で開きます。
  Windows:
    cd Word配置ツール
    py -3 -m venv .venv
    .venv\Scripts\python.exe -m pip install -r requirements.txt
    npm ci
    npx playwright install chromium

  macOS / Linux:
    cd Word配置ツール
    python3 -m venv .venv
    .venv/bin/python -m pip install -r requirements.txt
    npm ci
    npx playwright install chromium

  Linuxでは追加のOSライブラリが必要な場合があります。
  担当者に npx playwright install-deps chromium の実行を依頼してください。
  venvがない場合はOSのpython3-venvパッケージも必要です。
  フォルダを別PCに配布・移動した場合は、.venvとnode_modulesを除いてコピーし、
  移動先で初回セットアップをやり直してください。

■ 手順

【1】教室の情報を入れる

  友達紹介カード_編集用テンプレート.html をダブルクリックしてブラウザで開きます
  （Google Chrome 推奨）。画面上部の入力欄に次を入れます。

    教室名          例）久保田学園　板宿教室
                    ※「久保田学園」と教室名の間は全角スペース
    キャッチコピー  初期値）キミの「わからない」を「できる」に。

  教室名は表面と裏面の両方に自動で入ります。片方だけ直す必要はありません。


【2】写真枠の形を選ぶ

  手持ちの写真に合わせて選びます。選ぶと表面のレイアウトごと切り替わり、
  写真と文字の重なり方や、文字にかかる白いぼかしの範囲も一緒に変わります。

    選択肢            レイアウト          枠の大きさ    推奨サイズ
    ----------------------------------------------------------------
    たて長 31:55(初期) 右側の柱           62×110mm      1240×2200px以上
    たて 2:3           右側の柱(やや広い)  73.3×110mm    1240×1860px以上
    たて 3:4           右側の柱(広い)      82.5×110mm    1240×1653px以上
    正方形 1:1         大きめの角版        92×92mm       1240×1240px以上

  写真は「たて位置」で撮ったものを使ってください。
  よこ位置の写真は、このカードのレイアウトでは扱いません。


【3】写真を入れる

  「写真」ボタンを押すか、カード上の写真枠をクリックして画像を選びます。
  先生と生徒が写っていて、顔が中央〜右寄りに来るものが合います。

  入れたあと、「写真の左右／上下／拡大」のつまみで、枠の中の見え方を調整できます。
  文字が写真の濃い部分にかかって読みにくいときは、写真をずらすか、
  【5】の「配置をドラッグで調整」で写真枠ごと動かしてください。


【4】QRコードを2つ入れる

  「教室詳細QR」「申込フォームQR」から、それぞれ教室のものを入れます。

    ・白い余白を含む正方形の画像
    ・教室詳細＝時間割・教室ページ／申込フォーム＝体験・問い合わせフォーム
    ・2つとも必ず教室ごとのURLに差し替えてください


【5】文字を直す

  カードの文字はクリックしてそのまま書き換えられます。
  文言を変えない場合は、この手順は飛ばして構いません。

  位置を動かしたいときは「配置をドラッグで調整」を押してから、要素をドラッグするか
  矢印キーで動かします（矢印＝0.5mm、Shift＋矢印＝2mm）。
  終わったら「調整を終了」を押します。

  「A4・10面プレビュー」で仕上がりを確認できます。


【6】保存する

  「編集済みHTMLを保存」を必ず押してください。
  写真・QR・文字がすべて入った1つのHTMLとして保存されます。

  保存されたファイル（例：友達紹介カード_板宿教室_編集済み.html）を、
  このフォルダの中に置いてください。

  ※保存を忘れると、ブラウザを閉じた時点で編集内容は消えます。


【7】Wordファイルを作る

  Windows: Word配置.bat をダブルクリックします。
  macOS: 起動ファイルをダブルクリックします。
  Linux: このフォルダで python3 Word配置.py を実行します。
  macOSで実行権限がない場合は sh Word配置.command でも起動できます。
  HTMLを明示する場合は python3 Word配置.py "保存したHTMLのパス" を実行します
  （Windowsでは python3 の代わりに py -3 を使用）。
  フォルダ内の最新の「〜_編集済み.html」から、A4・10面のWordファイル
  （例：友達紹介カード_板宿教室.docx）が作られます。表が1ページ目、裏が2ページ目です。

  ※初回は macOS の警告が出ることがあります。その場合はファイルを右クリック →
  「開く」→「開く」を選んでください。


【8】Wordから印刷する

  できた .docx を Word で開いて印刷します。

    用紙  ： A4
    倍率  ： 100%（実際のサイズ）
    両面  ： 短辺とじ
    ページ： 1ページ目＝表面10枚／2ページ目＝裏面10枚

  必ず最初の1枚で、向き・表裏の位置・QRの読み取りを確認してから、
  まとめて印刷してください。


■ 注意

  ・ブラウザからは直接印刷しません。環境によって余白や倍率がずれるため、
    必ずWordファイルから印刷してください。
  ・修正はHTMLで行います。Wordファイルを直接いじっても、次に 起動ファイルを
    実行すると上書きされます。文字や写真を直すときは編集用HTMLに戻ってください。
  ・10面用紙は、1面 91×55mm・2列×5段・左右余白14mm・上下余白11mm のものです。
    手持ちの用紙の寸法が合うか確認してください。
  ・素材は一時フォルダで作成し、処理終了時に削除します。
  ・教室名のWindowsで使えないファイル名文字は「_」になります。
  ・フォントはPCに入っているものを使います。OS間で文字の見え方が変わる場合は、
    同じ日本語フォント（例：Klee One）を各PCに入れ、試し刷りしてください。


■ うまくいかないとき

  「編集済みHTMLが見つかりません」と出る
    →【6】の保存を行い、保存されたHTMLをこのフォルダに置いてから再実行

  Node.js・Python・docx・playwright・Chromiumがないというエラーが出る
    → 初回セットアップを行ってください。Chromiumがない場合は
      Word配置ツール内で npx playwright install chromium を再実行します。

  Wordファイルを置き換えられない
    → 同名のWordファイルを閉じ、出力フォルダの書き込み権限を確認してください。

  「次が未設定です：〜」と出て、Wordが作られない
    → 写真・教室詳細のQR・申込フォームのQR のうち、まだ入れていないものがあります。
      3つとも入れてから【6】の保存をやり直し、もう一度 起動ファイルを実行してください。
      未設定のまま印刷すると、点線の空枠がそのまま刷られてしまうため、途中で止めています。

  「教室名が「〜」のままです」と出て、Wordが作られない
    → 教室名が初期値（久保田学園　○○教室）のままです。【1】で教室名を入れ、保存し直してください。

  文字がはみ出す・重なる
    → 編集用HTMLに戻り、文字を短くするか「配置をドラッグで調整」で位置を直す

  QRが読み取れない
    → 白い余白を含む正方形の画像に差し替え、原寸で試し刷りして再確認
